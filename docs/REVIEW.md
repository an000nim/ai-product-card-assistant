## Происхождение и воспроизводимость

Локальные запросы выполнены 04.11.2026 с `LLM_BACKEND=ollama`, `LLM_MODEL=qwen3:4b-instruct`, `OLLAMA_CONTEXT_SIZE=3072`, `LLM_MAX_ATTEMPTS=2`. На каждом товаре выбрана первая попытка. Каждый запуск включает генерацию и самопроверку той же моделью. Метрики запросов сохранены внутри результата. Модель выгружается после запроса через `keep_alive: 0`. Максимальная сумма токенов запроса и ответа среди сохранённых запросов — 1974, меньше 3072.

После запуска дополнены проверки неправильного ввода и ответов API. Тесты `test_saved_pipeline.py` пропускают исходные сохранённые ответы через нынешний обработчик: текстовые поля, характеристики, пропуски, источники и трассировка совпадают. Это воспроизведение обработки с подменой API, а не повторная генерация. Новые реальные запросы могут дать другой текст; сохранённые результаты не доказывают качество каждого будущего запуска.

## Проверки и границы вывода

66 автоматических тестов прошли: валидация, CLI, ошибки API и ответов модели, пропуски данных, повторная генерация, сохранение исходных характеристик, некоторые смысловые ловушки, обработка сохранённых реальных ответов. `tests/check_examples.py` подтвердил формальные ограничения для обоих примеров. Тексты, числа, знаки и оговорки сверены ассистентом с входными фактами; новых неподтверждённых технических значений в итоговых карточках не обнаружено.

Самопроверка той же моделью и совпадение чисел не гарантируют истинность. Пустой `automated_issues` не разрешает автоматическую публикацию. Длинные входы, произвольные типы приборов и неизвестные формулировки требуют дополнительных проверок; профили обязательных характеристик неполны. Статус результата всегда требует проверки человеком.
