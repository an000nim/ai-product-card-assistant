# Сопроводительное сообщение

Инна Сергеевна, здравствуйте!

Подготовил локальный прототип AI-помощника на Python. Он принимает JSON товара и через API Ollama формирует SEO-заголовок, описание, поисковые фразы и коммерческий блок. Исходные характеристики сохраняются отдельно, пропущенные и спорные данные отмечаются.

Репозиторий: https://github.com/an000nim/ai-product-card-assistant.

В README есть инструкция запуска, описание промптов, решений и ограничений. В examples/results сохранены реальные результаты для двух товаров из каталога: ТРМ151-Щ1.РР.01 и ДТС014-50М.В3.25/0,2. Добавлены автоматические тесты и проверка требований к примерам.

Основные сложности — ограниченная память локального компьютера и точность технических формулировок. Для Ollama ограничен контекст; добавлены проверки и повторные запросы с замечаниями. В результатах сохранены исходные ответы модели и сведения о программной обработке. Противоречие источников по нагрузке реле отмечено для уточнения. Итог остаётся черновиком для проверки контент-менеджером: автоматические проверки не гарантируют отсутствие всех смысловых ошибок.
